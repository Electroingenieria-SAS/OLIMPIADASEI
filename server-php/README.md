# Servidor PHP alternativo (NO se despliega en Pages)

Estos archivos son referencia del prototipo inicial. Para usar PHP en un alojamiento PHP independiente, colocar `api.php` y `admin.php` en la raíz del juego y crear `storage/` con protección para escritura. GitHub Pages **no ejecuta** estos archivos.

No publicar directorios `storage` o contraseñas de administración en el repositorio. La API es para piloto, no validación competitiva antifraude.
